Definition of Done (Meta Final Innegociable):

Módulo de Campañas Masivas activo en ATAIR SGI que permite seleccionar segmentos de contactos o cartera total, previsualizar plantilla oficial aprobada por Meta, enviar a través de n8n/Meta Cloud API con tasa controlada (rate limiting), y reflejar el estatus de entrega y lectura en la bitácora de cada cliente.

Manifiesto Operativo: Alcance, Arquitectura y Hoja de Ruta

🎯 1. Objetivo de Negocio

Dotar a Match Home y ATAIR SGI de una máquina de difusión masiva oficial por WhatsApp. Enviar novedades de inventario y oportunidades de inversión a prospectos y colegas de bolsa inmobiliaria con un solo clic, sin chips quemados ni bloqueos de WhatsApp Web.

⚡ 2. Foco Actual (Fase 2)

Benchmarking del pipeline: orquestación de colas asíncronas mediante n8n conectado a Meta Cloud API v21.0. Esto evita congelar el navegador o rebasar los timeouts de 10s en Vercel cuando se envían lotes a cientos de contactos.

🚀 3. Stack & Método
  • Meta WABA Oficial: API v21.0 con System User Token (1 a 1)
  • Evolution API: Escucha pasiva de grupos (@g.us) con número satélite
  • Cola n8n + Gemini: Rate limiting y parser semántico de necesidades
  • Trazabilidad: Bitácora viva en Firestore
